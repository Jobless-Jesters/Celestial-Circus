## Git Conventions

### Commit Messages

1. Start with what the type of change you are making.
2. Followed by a short, concise message describing the change.

#### Examples:

    feat: implented feature A
    
    fix: bug fix function A
    
    refactor: refactored function A and B
    
    docs: updated documentation for X
    
    chore: cleaned up X and Y

### Branches

1. Use grouping tokens (words) at the beginning of your branch names.
2. Define and use short lead tokens to differentiate branches in a way that is meaningful to your workflow.
3. Use slashes to separate parts of your branch names.

#### Examples

    feature/add-function-A

    fix/bug-B

    chore/update-dependencies
